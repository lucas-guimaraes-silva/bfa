# bfa — redirecionamento

**Este repositório não tem conteúdo.** Ele existe só para que o endereço
antigo do site continue funcionando.

O projeto real está em **[brasil-financas-atlas/bfa](https://github.com/brasil-financas-atlas/bfa)**
e o site em **https://brasil-financas-atlas.github.io/bfa/**.

## Por quê

Em 06/08/2026 o repositório de conteúdo foi transferido para a organização
`brasil-financas-atlas`. O GitHub redireciona a URL do *repositório* depois
de uma transferência, mas **não redireciona o GitHub Pages** — o endereço
`lucas-guimaraes-silva.github.io/bfa/` passou a dar 404 imediatamente,
quebrando qualquer link já divulgado para alunos do NIF.

Este repositório reocupa aquele endereço e reenvia todo mundo para o novo.

- `index.html` — redireciona a home.
- `404.html` — o GitHub Pages entrega este arquivo para qualquer caminho que
  não existe aqui, ou seja, para todos os links de unidade. Ele aproveita o
  caminho da URL e leva a pessoa à **mesma página** no endereço novo, em vez
  de jogar todo mundo na home.

## Não apague

Enquanto existir link antigo circulando (mensagem de WhatsApp, slide, print,
resultado de busca), este repositório precisa continuar de pé. Ele não custa
nada e não precisa de manutenção.
